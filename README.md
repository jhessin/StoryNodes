# StoryNodes

A node based story generator for Godot inspired by [DialogueNodes](https://github.com/dlarv/DialogueNodes)

## Support

StoryNodes is free and open source, built and maintained on my own time.
If it helps you build stories in Godot, consider supporting its development —
contributions go toward the time I spend fixing bugs, adding features, and
keeping it working with new Godot versions.
